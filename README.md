# Toast POS — เมนูใช้งานง่าย v13

เวอร์ชันนี้รวมการแก้ไขเดิมทั้งหมด และปรับหน้า **จัดการเมนู** ดังนี้

- เลือกดูทีละหมวดด้วยแถบเมนูด้านบน
- ค้นหาชื่อเมนู และกรองเมนูร้าน/เครื่องดื่ม
- แสดงคำว่า “แก้ไข” และ “ลบ” ให้เข้าใจง่ายขึ้น
- บนมือถือแสดงรายการก่อนฟอร์ม พร้อมปุ่มเพิ่มรายการ
- คงระบบเครื่องดื่ม ตัวเลือกเสริม เมนู Custom คำเรียกแทน และพื้นที่จัดส่งเดิม

Cloudflare Workers ใช้ `worker.js` เป็นไฟล์หลัก และใช้ไฟล์หน้าเว็บจาก `dist-package/dist` ตาม `wrangler.jsonc`
